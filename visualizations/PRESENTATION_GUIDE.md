## 🎨 **DESIGN GUIDELINES**

### **Color Palette - Professional Saudi Theme**

**Primary Colors:**
```
Saudi Green:    #006C35
Saudi Gold:     #FFD700
Deep Blue:      #1B4B7A
```

**Secondary Colors:**
```
Data Blue:      #4472C4
Data Orange:    #ED7D31
Data Green:     #70AD47
Data Red:       #C5504B
Neutral Gray:   #7F7F7F
```

**Background Options:**
- White background with colored accents (most professional)
- Dark blue with white text (executive style)
- Gradient (blue to green) for cover slides

---

### **Typography Guidelines**

**Fonts:**
- Headers: Arial Bold or Calibri Bold (18-32pt)
- Body: Arial Regular or Calibri Regular (12-16pt)
- Data/Numbers: Calibri or Consolas (14-18pt)

**Arabic Text:**
- Use fonts that support Arabic: Arial, Calibri, Tahoma
- Slightly larger size (+2pt) than English for readability

**Hierarchy:**
- Slide Titles: 28pt Bold
- Section Headers: 20pt Bold
- Body Text: 14pt Regular
- Footnotes: 10pt Regular

---

### **Layout Best Practices**

**Spacing:**
- Margins: Minimum 0.5" on all sides
- Line spacing: 1.2-1.5 for body text
- Space between elements: At least 0.25"

**Alignment:**
- Left-align body text
- Center titles
- Right-align Arabic text (if needed)

**Charts:**
- Maximum 1 complex chart per slide
- Maximum 2 simple charts per slide
- Always include title and source

**Text:**
- Maximum 6 bullet points per slide
- Maximum 6-8 words per bullet
- Use parallel structure

---

### **Chart Integration Guidelines**

**From Excel:**
1. Create chart in Excel
2. Copy as enhanced metafile (better quality)
3. Paste into PowerPoint
4. Resize proportionally
5. Add border if needed

**From Power BI:**
1. Export visual as image (300 DPI)
2. Insert into PowerPoint
3. Maintain aspect ratio
4. Add title if not embedded

**Chart Formatting:**
- Remove gridlines if cluttered
- Use data labels for key values
- Consistent colors across all charts
- Clean, professional fonts
- Clear axis labels

## 🎬 **PRESENTATION DELIVERY TIPS**

### **For Executive Presentations:**
- Start with bottom line (key finding first)
- Use "So What?" test for every slide
- Limit data slides, focus on insights
- Prepare for tough questions
- Have backup slides ready

### **For Analytical Presentations:**
- Walk through methodology briefly
- Show data sources and quality
- Explain statistical significance
- Provide confidence intervals
- Anticipate technical questions

### **For Quick Briefings:**
- One key message per slide
- Visual > text
- No more than 1 minute per slide
- End with clear call-to-action

- Ensure proper character rendering
- Test on different computers

- Use Hijri calendar if appropriate
- Format numbers: 1,000,000 (with commas)
